# 350 种排版 · 流动图鉴

把 350 张排版参考卡片变成一个可以自由浏览的桌面端瀑布流：顺着画面寻找灵感，悬停查看线索，点击从原位展开，再复制感兴趣的设计描述继续创作。

这是 [jinhanbuilds](https://github.com/jinhanbuilds) 基于 [nevertoday/350-layout-compositions](https://github.com/nevertoday/350-layout-compositions) 制作的 Fork。原项目提供排版图片与分类资料；本 Fork 的主要贡献是交互浏览页面、图片对应的设计描述与一键复制体验。

**[下载并体验页面](https://github.com/jinhanbuilds/350-layout-compositions/archive/refs/heads/main.zip)** · [查看页面源码](index.html) · [浏览原项目](https://github.com/nevertoday/350-layout-compositions)

下载整个仓库并解压，使用桌面浏览器打开根目录的 `index.html`，即可浏览全部卡片，无需安装依赖或启动服务。图片文件夹需要与页面一起保留。GitHub 上的「页面源码」链接展示代码，交互体验请打开下载后的本地文件。

## 这个 Fork 增加了什么

- **自由浏览**：350 张卡片以瀑布流呈现，支持搜索和 8 个一级分类筛选。
- **悬停看线索**：鼠标移到卡片上，显示名称、分类与主题，帮助快速判断是否感兴趣。
- **原位展开**：点击后卡片从当前位置展开为悬浮详情，阅读高清图与文字说明；点击背景或按 `Esc` 回到浏览位置。
- **复制设计描述**：详情中展示可复用的设计提示词，按钮复制的内容与可见文本完全一致。

页面面向桌面端浏览，展开与收回使用连贯过渡，并支持系统的减少动态效果设置。

## 图片与文字来源

图片与原始分类资料来自上游项目，保留原作者署名及仓库的 [CC BY 4.0 许可证](LICENSE)。本 Fork 新增网页界面，并按图片中可见的标题校正网页展示信息；原图片文件名和原始目录继续保留。

页面中的「图片提示词」是围绕对应设计概念整理的可复用描述，并非原作者生成图片时使用的原始提示词，也不保证复现示例图。源图片包含少量同主题卡片，因此网页保留全部 350 张图片，允许主题重复。
