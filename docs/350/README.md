## 浏览方式

- 想系统学习：按 01–08 的顺序浏览。
- 想解决具体设计问题：直接进入对应媒介分类。
- 想查某个名称：在 GitHub 页面使用浏览器查找，或下载 [`catalog.csv`](../../v2/catalog.csv)。
